## Known contract gaps

- **File-based machinery is 82/105 dormant**: `behavior/core/import/` is 100% xfail (81/81, blanket
  "auto-ported CPython test; mamba promotion pending"), and ARCHITECTURE.md's own EC surface claims this
  surface is proven "NOT conformance fixtures ... `module.rs` `#[test]` units" — understating that 105
  conformance fixtures for it actually exist (82 dormant, 23 hand-authored live). Dormant-mass un-xfail:
  tracked: #1768. Stale EC-surface doc claim: no existing GitHub issue covers this specific path-drift (#1771
  is unrelated — runner-verdict sidecar/vacuous-walk scope); new finding, not filed.
- **Threaded-import cache divergence (new, no fixture proves it — the corpus that would is dormant)**:
  `MODULES` and `MODULE_VALUE_PTRS` are `thread_local!` (`module.rs:29,35`), but `threading_mod.rs:752`
  spawns real OS threads (`std::thread::spawn`). A module imported on one thread is invisible to, and not
  identical with, the same import on another thread — CPython's `sys.modules` is process-global. The only
  fixture cluster that would catch this, `behavior/std-libs/{pkg_import,threaded_import}` (9 files, ported from
  `test_importlib`'s own concurrency subpackage), is 100% xfail. #1770 does not cover this (its real scope is
  unrelated object-model/numeric divergences); new finding, no existing tracker found.
- **`__import__` returns a dict, not a module object**: `type(__import__("os")).__name__` is `'dict'` on
  mamba vs `'module'` on CPython (modules are bare dicts marked only via `MODULE_VALUE_PTRS`); pinned live by
  `_regression/core/imports/dunder_import_returns_module_raises.py` (xfail). Same shape as ARCHITECTURE's
  documented `__import__` fromlist/level/globals/locals drop. #1770 does not cover this (its real scope is
  unrelated object-model/numeric divergences); new finding, no existing tracker found.
- **`importlib` stubs pin shape, not function**: `reload()` is a no-op returning the same object
  (`importlib_mod.rs:99`), `find_spec` fabricates a 4-key all-`None` dict only for already-cached names
  (`:116`), `util`/`abc`/`machinery`/`resources` are empty. The 18-case manifest (plus the hand-authored 19th
  `_stub.py` placeholder) mostly proves callability + error shape (confirmed: `surface` ×9 callable/not-callable
  probes, `errors` ×4, `behavior` ×4), not real reload/spec-discovery semantics — no fixture actually reloads a
  changed file and observes the change. #1770 does not cover this (its real scope is unrelated
  object-model/numeric divergences); new finding, no existing tracker found.
- **Blocked-root path has zero fixture coverage**: `import gevent`/`greenlet` hard-raise `ImportError`
  (`module.rs:376`) with no conformance fixture in any dimension proving the raise or its message. New
  finding, no existing tracker found.
- **Sym-id collision guard (#983) and `FileId(9999)` hardcode** (`module.rs:1345`) have no fixture proving or
  disproving cross-module diagnostic/span correctness — both are mitigations for known-fixed regressions, not
  currently regressed, but undertested by the conformance corpus. New finding, no existing tracker found.
