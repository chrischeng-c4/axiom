# Mamba Coverage Evidence

Canonical coverage evidence for `projects/mamba/` lives in this directory.
These files replace the old project-root uppercase meta docs and keep the
producer commands next to the evidence they emit.

## Files

- `cpython-library-coverage-drilldown.md`
  - Generated by `tests/harness/cpython/tools/coverage_matrix.py`.
  - Producer command: `MAMBA_BIN=… tools/coverage_matrix.py --sample 8 --write`
  - Purpose: per-submodule drilldown that backs the collapsed top-level
    library coverage table in `projects/mamba/README.md`.
- `llvm-cov-baseline-2026-05-18.md`
  - Frozen `cargo llvm-cov --package mamba --lib --summary-only` snapshot from
    source commit `6edea62d5`.
  - Purpose: historical baseline for issue `#1885` child task `#1`.
- `llvm-cov-gap-ranking-2026-05-18.md`
  - Companion gap ranking generated alongside the frozen llvm-cov baseline.
  - Purpose: rank missed-region hotspots for follow-up work.
