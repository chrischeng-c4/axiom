# Next Step

## Goal

State the next useful action without taking it.

## How

1. Use the current conversation first. Do only the minimum read-only check, or use an available read-only specialist, when safety or correctness needs current evidence.
2. Give at most two options. Mark one as the recommendation.
3. For the recommendation, state its purpose, what completes it, and the needed authority, if any.
4. Honor Plan mode and any read-only mandate. Never execute the recommended action, edit files, change external state, or dispatch a writer.
5. If needed evidence is inaccessible, disclose the uncertainty and recommend that check. Do not turn it into a full investigation.

## Acceptance

The user can approve, reject, or refine one concrete next action from the response.

## Never

- Never present a completed action as pending.
- Never invent a target, authority, or approval.
- Never use this skill as authorization for later work.
- Never require AW, a plan file, or a special response format.
